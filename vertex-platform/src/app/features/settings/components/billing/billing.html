Gestión de Cuentas de Facturación para el Aprovisionamiento de Tiendas SaaS

← Volver

Cada shard es un proyecto de Google Cloud y todo proyecto debe estar vinculado a una Billing Account (la cuenta que paga). Un shard aloja hasta 35 tiendas; las tiendas dedicadas crean su propio proyecto.

¿Cómo funciona y cuáles son los límites?
  • Capacidad por cuenta: Google permite 5 proyectos por Billing Account. Las 2 cuentas de dev están al límite (5/5) — para sumar capacidad hay que pedir el aumento a Google (lo revisa soporte, no es automático).
  • Por qué no se pueden crear cuentas desde acá: Google no expone API para crearlas (solo la consola o soporte).
  • Shard "Listo": estado utilizable + billing + redirect URI registrado (único paso manual — el botón "Cómo configurar" lo explica).
  • Pool: el sistema mantiene shards calientes solo; si faltan, te avisa con el comando para reponerlos.
